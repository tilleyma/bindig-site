From Rekordbox to BINDIG and back

Two minutes, start to finish. Export your collection, scan it, then import only what you want. Your music files are never uploaded or changed.

Safe by design ✓ Exporting makes a copy of your library's details. It changes nothing. ✓ Scanning happens on that copy. BINDIG never connects to Rekordbox or your music files. ✓ Loading the BINDIG file in Rekordbox's preferences only shows it as a read-only list in the sidebar, like browsing a USB stick. ✓ Only you import. Import Playlist adds playlists. Import To Collection updates the tags of the tracks you select. That's it.
