Bring it into Rekordbox

Seven short steps. Your music files, cue points, beat grids and My Tags are never touched. Your progress is saved on this device.

  1. In Rekordbox: File → Library → Backup Library. It takes a minute and means you can always go back.

  2. Start small. This file changes just 10 tracks, so you can learn the steps on something harmless.

    These are the 10 tracks. Check them in Rekordbox after step 5:

    • Don't use File → Import. That menu only takes music files, so the XML will be greyed out.

      Open Rekordbox → Preferences → Advanced → Database. Under rekordbox xml, click Browse and pick rekordbox-bindig-trial.xml (usually in Downloads).

    • Click the rekordbox xml icon in the left sidebar, then open Playlists → BINDIG → Trial · 10 tracks. Click in the track list, press ⌘A (Ctrl+A on Windows), then right-click the highlighted tracks → Import To Collection.

      Right-click the tracks, not the playlist name. The playlist menu only offers Import Playlist, which copies the playlist but leaves your tags unchanged.

      Now check the 10 tracks from step 2. If any haven't changed, do Import To Collection once more. Rekordbox sometimes needs a second pass.

      Then repeat steps 3 and 5: Browse again and pick rekordbox-bindig.xml, open BINDIG → Fixed tracks, select all, Import To Collection.

    • Under the icon, right-click BINDIG → Purge → Import Playlist. The Purge playlists appear under your own Playlists, one per genre. They're your normal tracks, so you can preview, cue and play them as usual before deciding. Remove the ones you agree with. BINDIG never deletes anything.     Changed your mind?

    The undo file puts every approved track back exactly as it was. Import it the same way: Browse to rekordbox-bindig-undo.xml, open BINDIG → Undo, select all, Import To Collection. Or restore the backup from step 1.
